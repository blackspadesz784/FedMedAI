About this project

FedRad — Federated Chest X-ray Disease Detection.

What FedRad does

FedRad trains a single global deep-learning model to detect chest X-ray pathologies while keeping every patient image inside its own hospital. Four hospital nodes train locally on their own data; only encrypted model weights are shared with a central server, which aggregates them using Federated Averaging (FedAvg) to build one shared global model.

Why federated learning

Medical imaging data is sensitive and often cannot leave the institution that collected it. Federated learning lets multiple hospitals collaborate on a stronger shared model without any raw image ever being transmitted, copied, or centrally stored.

Tech stack

Frontend: HTML5, CSS3, vanilla JavaScript, Chart.js for charts. Backend: Python, TensorFlow/Keras, Flask REST API, run entirely from a Jupyter notebook. Model: transfer learning on a chest X-ray-adapted CNN backbone with Grad-CAM explainability.
